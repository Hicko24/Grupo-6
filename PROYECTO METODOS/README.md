# Proyecto Equipo 6 
## Predicción de Victoria o Derrota en League of Legends mediante Métodos Numéricos 04/02/2026

## Descripción del Proyecto
Este proyecto tuvo como objetivo analizar, mediante un modelo predictivo basado en ajuste de curvas por mínimos cuadrados multivariables, cuáles factores del macrojuego influyen con mayor peso en la probabilidad de victoria dentro de partidas clasificatorias del servidor EUN1. Para ello, se utilizó un dataset oficial de partidas reales y se aplicaron métodos numéricos vistos en el curso.

## Estructura del repositorio
- data/: contiene el dataset original ,el dataset filtrado y normalizado
- codigo/: contiene el script en Python para el filtrado de datos

## Metodología
El desarrollo del proyecto incluyó:

- Análisis y limpieza de datos.
- Selección de variables relevantes de macrojuego.
- Normalización de variables.
- Formulación del sistema normal de mínimos cuadrados.
- Resolución del sistema mediante métodos directos e iterativos.
- Interpretación de coeficientes y análisis de resultados.
